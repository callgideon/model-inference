## Ruling proposal (unnumbered)

LAB-REQUESTS: the Lab lists and opens requests only through lab-api's provider trace read (R176), as the signed-in user with the session's own access token and the session workspace as the provider; an unset `LAB_TRACES_API_URL` reads nothing. The list shows named metadata and a content label only (never content, organization, key or size), its URL carries only the route's own cursor, and 401/403 read as denied, 404 as not found, anything else as unavailable.
