## What it does

- `FeedbackProjector(outbox, projection, worker_id=…, batch=100, redelivery_s=30).pump()`: the relay hands out a
  claimed batch, each event with the durable row it names; the rows are inserted; then exactly the events whose row
  was inserted are acknowledged **as the claiming relay**. Insert failure: nothing acknowledged (claims lapse, events
  return). An event whose row its organization does not own: not projected, not acknowledged (visible as lag). Report
  `{read, projected, acknowledged, orphaned}`.
- `pg.PgFeedbackOutbox(connect)`: `pending` = one `UPDATE … WHERE event_id IN (SELECT … kind='feedback_projection'
  AND acknowledged_at IS NULL AND available_at <= now AND (unclaimed OR claim older than redelivery_s) … FOR UPDATE
  SKIP LOCKED) RETURNING event_id, org_id, (SELECT infrx.feedback_json(f) FROM infrx.feedback f WHERE f.feedback_id =
  payload->>'feedback_id' AND f.org_id = o.org_id)`: 0012's dispatch pattern on the database clock; the row is the
  durable one for the **event's own org**, never the payload (a label's event payload carries `calibration_set`: not
  authority). `acknowledge` lands only for `claimed_by = worker`. `lag()` = pending feedback events + oldest age.
  Runs as `service_role` (0004 DML); no SQL object added.
- `ClickHouseFeedbackProjection`: `feedback_events` (`ReplacingMergeTree`, key `(org_id, request_id, feedback_id)`),
  FINAL reads bound by org + durable request id (the trace projection's join key: late feedback joins by it, and needs
  no trace row). Columns: author principal, role, channel (the method), name, JSON value, comment, calibration
  membership, rubric, operator marker, created_at. No judge column; nothing but durable rows is written.
- **T2I WR-3 (carried):** `ship/pins.py` `PgPins(connect)(org_id, request_id)` = the coordinator's lookup, verbatim:
  `select model_id, requested_model, deployment_revision_id, serving_version_id, rate_card_version, policy_version
  from infrx.jobs where org_id = %s and request_id = %s and accounting_regime = 'credit'` → `AdmissionPins | None`;
  any PostgreSQL failure (connecting included) → `DependencyUnavailable` (`pg_rows`, shared with the relay).
  `ship.build_shipper(limits, spool, *, prefix="infrx/", endpoint_url="")` → None unless `shipping_enabled(limits)`,
  else the shipper over `CLICKHOUSE_URL`, `S3_TRACE_BUCKET`, `PgPins(connector(DATABASE_URL))` (+ T3's retention from
  `8b74fb88`). The composition-root call stays a wiring request (WR-T-4).
