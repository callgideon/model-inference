- Console suite and lint (`pnpm test`, `pnpm lint` in `apps/app`) **not run by this session**: `node_modules` absent, dependency manifests not owned here. No console file changed. Owner: coordinator / F2.
- The parity matrix is 106 scenarios × 4 environments, not an exhaustive product of inputs. Those belong to G/M/E oracles (MEDIA-SEC, API-STREAM, PERF-PILOT).
- `Auth.touch()` stamps `last_used_at` from `time.gmtime()` (wall clock), not the injected clock — identical to the old behavior with the default clock, but an injected clock does not drive that one value. Left as-is deliberately: `time.gmtime(self.rt.clock())` would add a clock read the old module did not make, which the parity harness compares. Owner: G, together with the rest of the auth surface. `infrx/auth/keys.py:67`.
- Legacy-shim hazards (documented shelf life, accepted for F1): assignments to `gateway.hmac` / `address_allowed` / `cost` / `_put` / `THINK` rebind `infrx` **module** globals, so they affect every app in the process, not only the default one; old names outside the table (`gateway.time`, `gateway.subprocess`, `gateway.asyncio`, the route functions) are accepted on assignment but inert, so a future test patching them would silently patch nothing; `app` is reachable only through `__getattr__`, not through `vars(gateway)`; `del gateway.<table name>` raises `AttributeError`. The table should shrink to nothing once G moves the tests to `create_app()`.
- Behavior preserved on purpose, including known weaknesses that are **not** F1's to fix (listed so they are not mistaken for regressions): 429 is checked after authentication but before media work; `/health` echoes upstream exception text; with neither `GATEWAY_API_KEY` nor `SUPABASE_URL` set the gateway serves unauthenticated; the streaming `<think>` strip is a first-chunk heuristic that mangles a reasoning block split across chunk boundaries; the legacy `usage_events` row carries `cost_usd: 0` and is recomputed by the shipper; usage rows for legacy-key requests never reach Supabase; `prepare_video` validates then connects, so the documented DNS-rebinding window remains; `USAGE_FAILED_LOG=""` still means "spill nowhere, log the loss" (now faithfully). Owners: G (gateway/auth/limits), M (media), D (accounting).
- Pre-existing, not a regression: the baseline suite is import-order dependent. Running `test_media`/`test_inflight` before `test_gateway_auth` fails the same 7 auth cases at `25b9829` and at `97c43ea` (`gateway` is imported before `test_gateway_auth` sets `SUPABASE_URL`/`GATEWAY_API_KEY`). F2's pytest configuration must not reorder these files, or should move the environment setup into a `conftest`.
- `create_app()` builds its default clients eagerly (unchanged from the old import-time behavior), so a caller injecting neither `client` nor `sb` still constructs two `httpx.AsyncClient` objects. Harmless (no connection until first use) but worth knowing when many apps are built in one process.
