## Ruling proposals (unnumbered; rulings run through R249)

- **Verdict of a running release.** The Lab page's verdict of a running release is D9's latest
  decision, or else R2's `evaluate` at read time over D9's Live (0054) and the release's B2
  report (WR-C5-REPORT's selection). It is read-only and never recorded. It is null while
  nothing is assigned (R244) or the plan's unit is refused (R248). The route's expansion
  proposal gate (`verdict.action == "expand"`) reads it (WR-LR6-VERDICT).
- **E2E suites read the Lab control unit's composition.** The Lab e2e suites read the page
  through the Lab control unit's own composition (R186/R237, `pilot._lab` via
  `infrx.lab.control.app`), never through a route the backend registers beside it. Stand-ins
  are limited to seams the unit reads through (the objects, the session door) and are named in
  the suite's record.
