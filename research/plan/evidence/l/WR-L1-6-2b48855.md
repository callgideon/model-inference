## Design (one line each)

- `lib/auth/sign-in.ts` ("use server"): `signIn(state, formData)` = password sign-in on the Lab's own session client (`clientOptions`, the `sb-infrx-lab-auth` host-only cookie) then `redirect("/")`; any auth error, missing field or thrown transport = `{error:"failed"}`; misconfigured = `{error:"unavailable"}` with no client built. `signOut()` ends the session and deletes the workspace preference cookie.
- `lib/auth/sign-in-form.tsx` (client): `useActionState(signIn, null)`; shows only `SIGN_IN_COPY` (fixed, in access.ts), never the auth server's text. Password only: consumer signup/recovery stay in the App.
- `lib/auth/routes.ts`: `authCallback(request)` verifies a PKCE `code` or a `token_hash` of type `magiclink`/`email` only, writes the cookie onto the response and always redirects to the **configured** origin's `/` (never the request Host, never a `next` parameter); `refreshSession(request)` = the proxy: `getUser()` on the Lab client, refreshed cookies onto `NextResponse.next`, never a redirect (access stays the guard's).
- `request.ts`: `clientOptions(config, store)` extracted (guard + sign-in share one cookie discipline).
- `(provider)/layout.tsx`: signed-out renders the sign-in form (the "sign-in page" is `/`'s signed-out state; a layout cannot read searchParams, hence `useActionState`); ready, select and denied each offer sign-out.
- `tests/l/shell/boundary.test.ts` `PUBLIC`: the only unguarded entry points, named exactly (`lib/auth/sign-in.ts` signIn/signOut; `app/auth/callback/route.ts` GET). A neighbour export in the same file, or another route, is still flagged (self-check list).

## Wiring requests

- **WR-L1-6a** `apps/lab/app/auth/callback/route.ts` (new):
  ```ts
  import type { NextRequest } from "next/server";
  import { authCallback } from "@/lib/auth/routes";

  // WR-L1-6: public by design (tests/l/shell PUBLIC): email links land here before any session exists.
  export function GET(request: NextRequest) {
    return authCallback(request);
  }
  ```
- **WR-L1-6b** `apps/lab/proxy.ts` (new; Next 16 names middleware "proxy"):
  ```ts
  import type { NextRequest } from "next/server";
  import { refreshSession } from "@/lib/auth/routes";

  // WR-L1-6: keep the Lab session cookie fresh on every request; access is decided by the guard.
  export function proxy(request: NextRequest) {
    return refreshSession(request);
  }

  export const config = { matcher: ["/((?!_next/static|_next/image|favicon.ico).*)"] };
  ```
