## What was built

1. **Engine pin** (`models/marlin2b/serve.sh`, `models/marlin2b/serving-version.json`). The
   record is serve.sh's **pinned default, verified by `check_pinned_launch`** on a launch
   with no extra arguments. The image is pulled by registry digest and an `IMAGE` in the
   environment is ignored (PIN-2); `--max-model-len` and `--gpu-memory-utilization` are
   literals; the engine is published on `127.0.0.1` only and takes no `--api-key`;
   `--max-num-seqs` comes from `ENGINE_MAX_NUM_SEQS` (a positive integer; default 8, the
   pilot setting, ⚠️ the box ran 32) and `--allowed-local-media-path` from
   `PROCESSING_CACHE_DIR` (absolute, canonical, not a system directory; mounted read-only
   at the same path); a second command-line value for either, or an `--api-key`, is
   refused (exit 2) before docker runs. Other vLLM flags a caller appends pass through and
   are outside the record. The record carries the model pins, the image resolution (an
   index digest), every flag as served, both EOS ids, profile `v1` and an
   `engine_options_digest`.
2. **One media root.** `VllmEngine`'s root is `PilotSettings.processing_cache_dir`
   (`PROCESSING_CACHE_DIR`) — the value M2's `ProcessingCache` and serve.sh read.
   `LOCAL_MEDIA_ROOT` is deleted; an unset root refuses every video `dependency_unavailable`.
3. **Drain** (`WorkerService.stop`, `WorkerLoop.drain`): stop claiming, wait up to the bound
   (default: the generation budget), cancel the rest — released, never settled — and record
   per job what ended (job, cause) and what was released. A drained loop stays drained.
   `serve()` maps SIGTERM and SIGINT to the drain, and **returns by itself when any runner
   or the reaper dies** (crash-only), after draining what still runs.
4. **Protected readiness/liveness**: `GET /readyz` and `GET /livez` on a loopback-only
   listener (any other host refused at construction **and at start**; the listener is bound
   **before** anything is reaped or claimed). `/readyz` is 200 only for an engine that
   answers ready within `HEALTH_TIMEOUT_S`, a pool that is running and not draining, and a
   live worker; `/livez` is 503 once anything died unasked - the whole pool, one runner
   (`runners_dead`), or the reaper (`reaper: dead`). The body names `engine`
   (`up`/`down`), `loop` (`idle`/`busy`/`draining`/`stopped`), `reaper`
   (`running`/`dead`/`stopped`). Counts only.
5. **The `recover` reaper** (worker side): `JobStore.recover()` once at start-up before the
   pool exists, then every 10 s; every `IndexEvent` returned is enqueued; a failing
   `recover`, a garbage answer or a failing `enqueue` is counted and retried.
   **PERF-PILOT hook**: `AttemptResult.timings` (`prefill`, `generate`, `journal`,
   `persist`, `settle`, ms on the injected clock, absent when the phase did not happen) and
   `server_timing()`, which `bench.parse_server_timing` reads back unchanged.
6. **Measurement scripts** for the coordinator: `models/marlin2b/measure/inventory.sh`
   (read-only; exits 2 on a missing container), `capability.sh` (inference requests only),
   `concurrency.sh` (E1B cell L1; loads the engine; survives a failed scrape).

## Failure drill

| Injection point | Durable state before → after | Duplicate / retry behaviour | Cleanup |
|---|---|---|---|
| Worker dies holding a lease (claim, no run, clock past TTL) | `running` → reaper: `queued`, `attempt=1`, one index event | the next claim is generation 2; the dead lease is never resumed | `reaped` counts it |
| Worker dies after publishing | `running` (published) → `failed`/`lost_after_publication` by `recover` | nothing enqueued, never regenerated | — |
| `recover` raises (store down) | unchanged | retried next tick; the process lives | `reap_errors += 1` |
| `recover` answers garbage (not a list) | unchanged | counted like a store that is down; the timer goes on | `reap_errors += 1` |
| `enqueue` raises after `recover` requeued | `queued` durably, index missing it | Q's reconciler / next rebuild repairs; never lost | `reap_errors += 1` |
| Drain bound passes with an attempt in flight | `running`, lease held → unchanged (nothing settled), stream closed | past the TTL the next start-up reap requeues it; it completes once as generation 2 | `released_jobs` records it |
| SIGTERM or SIGINT to a serving process | as above per attempt | exit 0; the in-bound attempt settles `completed` | report printed |
| Stop immediately after start | pool not yet running | the drained loop stays drained; the pool stops | — |
| Engine process SIGKILLed | readiness `down`, pool live; a new attempt settles `failed`/`engine_error`, debit 0 | a restarted engine is `up` again | fake server stopped by the fixture |
| **One runner of several dies** (a transient index error) | the others go on; `/livez` 503, `runners_dead 1` | `serve()` drains the survivors and returns; the service manager restarts the process at full concurrency | `failures == 1` |
| Every runner dies (index unreachable) | pool stops; `/livez` 503; `serve()` returns | the service manager restarts the process | `failures == 1`, `runners_dead` |
| The reaper dies (a defect outside its guard) | lost leases would stay unreaped | `reaper: dead`, `/livez` 503; `serve()` drains and returns for a restart | — |
| Readiness port already taken | nothing claimed, nothing reaped | `start()` raises `OSError` before the pool exists; a restart loop orphans nothing | — |
