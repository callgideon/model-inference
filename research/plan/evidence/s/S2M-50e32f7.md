## Failure drill

There is no runtime behaviour to inject a fault into. The analogous adversarial work — and
what it found — is the cross-check of the **intended** contract against the **actual** code,
which produced fourteen recorded discrepancies (`marlin-sop.md` §4). Three of them are
fail-stops that a document asserting "the endpoint serves video today" would have hidden:

| Injection (read a value the way the next hop reads it) | State found | Consequence |
|---|---|---|
| Feed an `M1`-produced `MediaRef` to `VllmEngine.upstream_body` | `MediaStaging.materialize` builds the ref with no `duration_s` (`media/store.py:178-181`); the field defaults to `None` (`contracts/records.py:429`) | `engine.py:570-578` raises `UnsupportedMedia("a prepared video must carry a positive, finite duration")`. **Every** video request on the pilot path fails at the engine. Recorded as D2, owner M2 |
| Follow `_part`'s output to vLLM | `{"video_url":{"url": "media/<org>/<profile>/<digest16>/source"}}` (`engine.py:530`) — a bare object key, not a fetchable URL, and nothing in the tree bridges key → bytes for the pilot path | The engine cannot open the media. The legacy path works only because it inlines a `data:` URL instead (`media/video.py:201`). Recorded as D3, owners M2 + W3 |
| Validate the frozen `storage_ref` of three v1 fixtures against the adapter that consumes them | `media/1a1a1a1a/22/source.mp4` fails `STORAGE_REF_PATTERN` (`engine.py:124-127`), which requires a full lowercase UUID org segment | `check_storage_ref` answers `not_found`. ## Limits

1. **The gated files were not re-verified from upstream.** `GET /resolve/main/config.json`
   returns 401 without `HF_TOKEN`, so `config.json`, `processor_config.json`,
   `preprocessor_config.json` and `generation_config.json` are quoted from the copies
   vendored in `research/models/marlin2b/` on 2026-09-19. The commit SHA those copies were
   taken at is unchanged (`fd111fca…`, re-confirmed today), which is the strongest
   verification available without the token.
2. **Four digests remain ⚠️ TO BE VERIFIED and they matter**: the two weight shards, the
   `tokenizer.json` content, and a runtime **image** digest (`serve.sh` pins the moving tag
   `vllm/vllm-openai:nightly`). Until they exist, "pinned serving version" is a label.
   Method for each is stated inline. Owner: I2B/W3 on an allocated host with `HF_TOKEN`.
3. **`shortest_edge` 4096 vs 65,536** is unresolved (`media/video.py:116` uses 4096;
   `models/marlin2b/tokens.py:47` also probes 65,536). 4096 is the pin because it produced
   the measured training grid. Method: one `tokens.py` run per variant. Owner M4/E1B.
4. **The profile has never been served end to end.** D2, D3 and D12 mean the pilot path
   cannot complete a video request in this tree, and the `--hf-overrides` remap has never
   been run on any of the eight pinned GPUs — only on the L40S dev box.
5. **No quality evidence of any kind.** Caption-event parity was observed on **one** clip.
   There is no accuracy baseline for Marlin-2B anywhere, quantised or not, and public
   benchmarks are contaminated as baselines (ActivityNet/Charades/TimeLens appear in both
   the training-source and evaluation lists). P-07 blocks any accuracy claim.
6. **P-18 latency and availability criteria are deliberately absent**, and the soak duration
   carries a proposed engineering floor marked ⚠️. No number in §5.2 may be quoted without
   its provisional label.
7. **`make check` was not run as a whole** (container-safety reason above), so this report
   cannot assert a clean full-tree check — only the two suites it did run.
8. **The `sop-synth-v1` fixture is a description, not a built artifact.** No media, manifest
   or generator script exists yet; it is an integration request to E.
