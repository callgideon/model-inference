## Proposed rulings (coordinator numbers)

1. The Lab control origin is one site file imported by the App edge through a single glob line; a
   Lab site is installed only after the App's and the Lab's composed configuration validates with
   the pinned Caddy, so a bad Lab deploy never changes the running App edge.
2. The Lab control unit starts only with the operator's `/etc/infrx-lab/enabled` marker; it has its
   own image variable (`INFRX_LAB_IMAGE`), env file, uid/group and resource bounds, and no systemd
   link to or from an App runtime unit. A Lab rollback restarts only the Lab unit.
