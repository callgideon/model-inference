## Design (N1.a/b/c)
- **Spec** `infrx.dataset_import.1` (pydantic, strict, extra forbidden): provider, import id, dataset id/version, created_at, modality (text | finite_video | structured), `ownership: provider_owned` only (P-09), licence, use restrictions, the D7 grant ref (immutable grammar; provider segment must be the spec's), `clock_unit` ms|s, annotation `{method, method_version, tool}`, dotted field paths `content`, `group`, `split`, and for finite video exactly `media`, `start`, `end` + clock unit. `parse_spec` refuses a spec that is not the caller's server-derived provider's (`Forbidden`).
- **Rows**: bounded (`MAX_ROW_BYTES` 1 MiB; the stream never buffers past it), JSON objects only (NaN/Infinity refused), mapped fields present, text non-blank / structured+video object-or-array, group string|int, split in train/validation/holdout, spans whole milliseconds after unit conversion (`Decimal`, never rounded; `0 <= start < end <= start + 82 000`), media a relative bundle key (`[A-Za-z0-9_-][A-Za-z0-9._-]*` segments: no `.`/`..`, no scheme, no absolute path, no backslash) or an http(s) URL. Closed reason vocabulary `REASONS`; each rejection is `{line, reason, detail}`.
- **Media** through M's ports: bundle key `lab/<provider>/imports/<import id>/bundle/<path>` (provider-scoped by construction), `describe` first (over `MAX_MEDIA_BYTES` → `too_large` unread; non-video type → `unsupported_type`), then `get`; URLs through `MediaFetcher` (pinned, SSRF-hardened, byte-capped); the clip is copied write-once to `lab/<provider>/media/<hex>`.
- **Staging / resume / dedup**: spec written once at `…/spec.json`; lines grouped into fixed chunks (`chunk_rows`, default 500) written once at `…/staged/<n>.json` with their outcomes and the digest of the lines they cover; each accepted row's content object (`{modality, content, original, annotation, media_digest?, span_ms?}`, RFC 8785) is written to `lab/<provider>/samples/<hex>` before its chunk. A rerun reuses a chunk whose lines match and refuses (`Conflict`) one whose lines changed; the spec likewise. Duplicate content → `duplicate` naming the first line; a declared group in two splits → `split_conflict`; both survive a resume (restored from stored chunks). Sample id = UUIDv4-shaped `sha256(dataset_id \n content digest)`; unmapped group = the content digest; unmapped split = train.
- **Publication (N1.c)**: refused (`ImportRejected`, carrying the full report) while any row was rejected unless `accept_rejects=True`, and always when nothing was accepted; then `register_source(source_id = import id, content digest = sha256 of the whole upload, grant ref)` and ONE `publish` of the `lab.dataset_manifest.1` (derivation `import`) through D7 (atomic there). A crash anywhere before publish publishes nothing; a rerun replays the source and publishes once. The report returns accepted count, every rejection, dataset and source refs.
- **Schema preview**: top-level field → JSON types, checked mapped values or refusal per row, capped, blank lines skipped, no I/O.

## Oracles
- DATA-IMPORT: malformed rows (8 kinds) quarantined with line+reason; oversized row (in pieces and in one piece), clip (refused unread) and upload (`RequestTooLarge`, nothing published); timestamp units (unknown unit refused before reading; fractional ms, backwards, empty, negative, boolean, > 82 s, sub-ms seconds quarantined); traversal/absolute/scheme/backslash/foreign-provider paths, SSRF to 169.254.169.254 (refused by M's fetcher), non-video object; crash after 1..8 writes and between source and manifest publishes nothing, resume publishes the uninterrupted run's exact ref, reusing staged chunks; replayed upload = same report, no new row (fake and real PG); changed bytes/spec/appended lines under one import id = `Conflict` (also when the first run died before registering its source); duplicates and group/split conflicts (also across a resume).
- DATA-RIGHTS: another provider's caller, a grant ref naming another provider (`Forbidden`), an unknown grant and another provider's grant id under this provider's segment (`NotFound`, fake and real 0029), `ownership` other than `provider_owned` (P-09), a revoked grant (`Forbidden`, no source registered, fake and real `lab_revoke_access_grant`).

## Proposed ruling (coordinator numbers it; next free R169)
- N1 imports: `infrx.dataset_import.1` is strict; only `provider_owned` data until P-09; a Lab source registered by an import is `source_id = import id`, digest = the sha256 of the whole uploaded JSONL; content objects are RFC 8785 `{modality, content, original, annotation, media_digest?, span_ms?}` at `lab/<provider>/samples/<hex>`; a publication with rejected rows needs the caller's explicit acceptance and always reports every rejection; staged chunks are write-once and an import id never names two uploads.
