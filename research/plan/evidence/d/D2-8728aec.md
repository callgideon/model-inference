## Limits

1. Not applied to any hosted project. 0003, 0006, 0008, 0009 are amended in place (all unapplied anywhere, per D1R Limits 1); 0010–0014 are new.
2. D2 terminalizes only on the preparation path (`preparation_failed`); the settling transaction (usage row, terminal journal event, `complete`, cancel, recover) is D3/D5. Terminalization writes `usage_projection`/`trace_projection` rows with the fake's payload shape; D5 may replace it.
3. CREDIT admission covers **consumer** keys through public listings. provider_dev endpoint resolution (`resolve_endpoint_pins`) is not built: a provider_dev key is refused `not_found` by `admit_credit` (the database guard for provider_dev jobs exists). The v1 port has no CREDIT read: `get_owned` refuses a CREDIT job; `get_owned_credit` returns `AdmissionV2`.
4. The admission lock is one global advisory lock (ponytail, documented); the per-connection `connector` opens a connection per call (pool: G/coordinator wiring).
5. `d1r_grant_race_arbitrates_one_index` (D1R's) is probabilistic: 1 survival in the plain sweep, killed 4/5 on repeat. Not D2 code (0006 grant untouched); reported for D1R/coordinator.
6. Pre-existing on the base, not D2: `tests/w/test_loop_mutants.py` collection error (breaks `make api-test`/`make check`), 6 failing `tests/m`/`tests/w` tests (reproduced on `git archive f302091`), and Q's Valkey-harness flake in the legacy-first run.
7. `media_uploads.max_bytes` is bounded at the frozen `MAX_MEDIA_BYTES` default (64 MiB); `duration_s` is required when finalized, as M3 specified verbatim (an upload with no decoder cannot finalize).
8. `set_price`/`unrevoke_key` test hooks disable one trigger for one statement in the test database (production cannot undo either); the `infrx_test` clock is fixture-only and gated.
9. Results are purged by nobody yet (retention follows `jobs.result_expires_at`, D5 sets it).
